# 各機關新聞整理 v2.1.22

本版將來源目錄由 73 個擴充至 88 個，新增文化部、內政部及衛生福利部主管的 15 個政府捐助財團法人官方新聞或機構公告入口。一般新聞媒體法人只收自身機構公告，不收日常媒體報導。

- 每個新增來源均保留法人名稱及主管部會，支援 `list-sources`、預設收集與 `--sources` 單一選取。
- 加入共用列表解析與必要的特定網站 adapter；無當週消息時回報零則，不視為解析失敗。
- 更新來源健康、公告分類、Excel 隸屬欄位及來源數驗收檢查。來源查核與未納入原因見 `docs/foundation-source-audit.md`。

維持既有的跨來源去重預設行為。下載後請使用 `SHA256SUMS.txt` 驗證檔案。
