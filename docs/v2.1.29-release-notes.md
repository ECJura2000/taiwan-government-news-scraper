# 各機關新聞整理 v2.1.29

## 全文與品質

- 修正行政院、高速公路局、交通部、外交部、教育部、文化部、勞動部、金管會及海巡署的新聞正文擷取；偵防分署共用海巡正文結構。排除導覽、頁尾、腳本及操作控制。
- 修正金管會 RSS CDATA 連結的 XML 查詢分隔符，避免原文連結導向列表頁。只有 PDF 附件的公告另記 `attachment_only`，保留新聞，不將附件標題當成全文。
- 已核對正文結構的十個來源，完整模式最後保留至少五篇新聞、全文覆蓋率低於 70% 時，產生來源別品質提醒。摘要模式及不足五篇不套用這項門檻；不刪除新聞或跳過全文補取。
- 2026-10-11 本機同週、同九個來源比較：兩次均保留同一組 123 則新聞，全文從 0 則提升到 122 則（99.19%）；剩餘一則為只有 PDF 附件的公告。這是限定案例的實測，不代表所有來源都有相同覆蓋率。

## 執行診斷

- 補齊資料模式比較、索引、報表組裝等連續階段計時；同時保留單調時鐘總時間與系統時鐘差。
- 新增 HTTP 請求、重試、快取重驗／命中及等待指標；逐篇全文補取保留 HTTP、Chrome 備援與解析時間。
- `.complete` 完成標記另記 JSON 序列化、fsync 與檔案雜湊時間。並行任務累計時間仍不能直接相加當成總執行時間。

## 日常來源檢查

- 共用發布的失敗預算：重測後仍失敗不得超過八個或 10%；持續解析、拒絕存取或瀏覽器錯誤仍阻擋。
- 同來源連續三次完整檢查仍失敗會阻擋；恢復則歸零，同一執行編號不重複累加。
- 從前次同分支 GitHub 執行產物讀回失敗歷史；即使門檻未通過仍上傳紀錄，產物保留 90 天。無法讀回或歷史格式錯誤不會靜默略過。

維持 88 個來源、CLI 選項、JSON schema v4、17 欄 Excel、預設完整模式，以及國防部官方主機 TLS 例外範圍。來源網站的臨時故障或拒絕存取仍會如實記錄；不將部分失敗描述為全部成功。
