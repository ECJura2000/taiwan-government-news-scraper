# v2.1.28：桌面介面更新

新版以「範圍確認 → 搜集新聞 → 查看報告」引導操作。首頁集中期間、主題、來源及儲存位置；來源可搜尋，進階選項預設收合，執行進度、取消與報告入口保留。

中文使用標楷體，英文與數字使用 Times New Roman；保留深淺主題及 100%–200% 文字放大，並調整較矮、較窄視窗的排列。字型使用作業系統已安裝字型，未內附字型檔；缺少指定字型時使用 serif 替代。

桌面介面預設上一個完整週（臺北時間），指定週與自訂期間分開選擇，日期未填完整或起日晚於迄日不能開始搜集。CLI 日期預設不變。

維持 88 個核准來源、JSON schema v4、17 欄 Excel、相關性深淺底色及既有完整新聞搜集方式。

前端檢查、建置、日期測試、Rust 回歸測試及來源目錄驗證納入發布檢查。macOS 已以實際打包程式確認介面；Windows／Linux 字型效果取決於系統已安裝字型。

本版另修正 CLI 完成 JSON／Excel 後的結束程序：網站逾時留下的背景 DNS／TLS 工作不再無限阻止程式退出。完整搜集與報告寫入仍須先完成；原有退出碼及品質判定保留。發布來源檢查可選 Ubuntu／Mac 執行環境，來源與失敗上限不變。
