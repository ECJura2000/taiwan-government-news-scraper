# 各機關新聞整理 v2.1.26

這版改善輸出可靠性與內容品質提示，讓每次執行的 Excel、JSON 和診斷紀錄能確實對上。

- **成對保存**：Excel 與 JSON 共用執行編號，完成後建立標記與 SHA-256 校驗值；同一週重跑保留獨立檔案，中途取消或發布檔案失敗會清除本次未完成輸出。全文與摘要模式各有獨立的最新執行指標。
- **內容品質提示**：介面顯示全文取得數、覆蓋率、摘要補位數與全文補取失敗數。Excel 以「列表摘要；未取得全文」或「未取得全文或摘要」標示內容狀態；全文模式至少 10 則新聞且覆蓋率低於 50% 時另顯示提醒。這項提醒不等於來源失敗。
- **發布前重試**：先重試失敗來源，再依最終故障類型判斷；失敗來源上限為 8 個且不得超過 10%。數位發展部、國發會、國科會及經濟部必須恢復；未恢復的解析、存取或執行錯誤阻擋發布。
- **設定檢查**：載入目錄即拒絕零值、欄位錯字、未知解析器、無效網址／CSS selector，以及未授權的 TLS 例外，並保留來源與欄位資訊。
- **回歸驗證**：加入真正 CLI 執行、解析結果傳到 JSON／Excel、校驗值、同週重跑、中途取消與保存失敗回復的測試；發布後下載測試也核對成對檔案。
- **依賴修補**：將間接前端依賴 `source-map-js` 更新至 1.2.2，修補新的高風險公告。

Excel 維持 17 欄與原有底色：高度相關為亮黃色、可能相關為淺黃色；有關聯主題的欄位仍標黃。摘要模式只輸出列表資訊，不補取全文或做關聯分色。

維持 88 個政府機關及主管財團法人來源、JSON schema v4 與既有 CLI。新 JSON 欄位以增補方式提供。排程請依 `latest_run.json`／`latest_summary_run.json` 及完成標記選取同一組檔案，詳見 [自動化協定](AI_AUTOMATION.md)。

下載後請以本版 SHA256SUMS 與 SIZE-MANIFEST 驗證。動態來源需要系統 Chrome／Chromium。本次發布不包含本機週報、執行紀錄、憑證或其他本機資料。
