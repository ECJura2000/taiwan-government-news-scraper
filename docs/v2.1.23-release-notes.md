# 各機關新聞整理 v2.1.23

本版將來源執行流程與 HTTP 傳輸政策拆分為穩定邊界，保留既有 CLI、88 個預設來源、Excel 工作表與 JSON 報告契約。

- 新增來源執行元件，負責 route 嘗試、browser／NPS 特殊處理與詳細內文補取；執行流程負責排程及結果彙整。
- 在來源目錄支援列表 route 與詳細內文各自宣告 transport policy，由通用 HTTP client 執行解析後的政策，不再內建站點名稱分支。
- 保留國防部受限 TLS fallback 與安全使用紀錄，並對瀏覽器最終主機執行檢查。
- 新增 mock HTTP 與固定案例契約測試，文件記錄重構前基準和相容性驗收。
