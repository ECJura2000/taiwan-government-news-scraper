# 各機關新聞整理 v2.1.24

本版修正國防部、客委會的新聞列表與全文取得，新增摘要模式、效能量測與初篩 shadow mode。預設仍抓全文並使用正式關聯性判斷，不會因初篩預測而刪除新聞。

## 來源穩定性

- 國防部：相容新版列表的日期、標題與相對連結，修正全文容器；首次 HTTP 等待調整為 12 秒／1 次，保留精確官方主機的既有 TLS 備援及診斷。
- 客委會：新增同一官方列表的 Chrome 備援；官方詳細頁在 HTTP 失敗或無內文時可使用限定主機的 Chrome 備援，逐篇原因及結果寫入 JSON。不新增不安全 TLS 例外。
- 公路局：依序使用官方 HTML、官方 JSON、Chrome；過期 JSON 不冒充成功空集合。真正的防護拒絕頁分類為 `access_blocked`，明確拒絕時立即停止等待，不繞過 CAPTCHA 或存取控制。
- 2026-09-28 至 2026-10-04 的本機指定來源實測，國防部 3 則、客委會 15 則均取得全文；公路局仍被網站防護拒絕。這是部分恢復，不是所有來源均已修復，也不是所有機關全文覆蓋率保證。

## CLI 模式與量測

```bash
news-scraper collect
news-scraper collect --content-mode summary
news-scraper collect --prefilter-mode shadow
```

- `full` 為預設：保留全文補取、正式政策分類、BM25 與既有輸出流程。
- `summary`：保留符合日期、新聞品質與去重規則的文章；只輸出來源、日期、標題、連結與列表摘要，不補抓摘要或全文。分類、分數留空；17 欄 Excel 檔名加 `_摘要`，避免覆蓋全文檔。必要的列表與日期解析存取仍允許。
- `shadow`：只適用 `full`，仍補取全部全文、維持正式結果；只記錄預測能避免的請求、提前去重差異及高相關／可能相關漏判。與 `summary` 同用會回報參數錯誤。
- JSON schema 維持 v4，採相容新增欄位：實際模式、逐篇狀態、各階段耗時及筆數、shadow 指標。正式分類未執行時使用 null，不以零分冒充無關。
- 並行來源耗時是各任務加總，不可與整體 wall time 混用；全文模式與摘要模式的集合差異逐篇記錄。本版不啟用依初篩跳過全文的正式模式，也不宣稱已達成 20% 可比效能改善。

維持 88 個來源、17 欄 Excel 及 Rust CLI／Tauri 共用服務。正式節流仍須累積 3–5 個可比週次，確認高相關零漏判、可能相關逐篇審查與效能／穩定性門檻。

發布前另更新前端間接依賴 `devalue` 至 5.9.4，修正已公告漏洞；不降低依賴稽核門檻。

下載後請以同版本 `SHA256SUMS` 與檔案大小清單驗證；動態來源需要系統 Chrome／Chromium。
