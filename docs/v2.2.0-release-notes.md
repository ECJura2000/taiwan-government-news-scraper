# v2.2.0

2.2 版保留全部 192 個核准来源，包含四部會擴充的 104 個來源與 72 個 RSS 優先來源。GUI、CLI、JSON schema v4、Excel 17 欄、預設全文、共用 RSS／網頁篩選及國家標準時間功能保留。

- 修正消防署、農科園區、國健署三個核准主機在 Linux 的官方 TLS 中繼鏈；保留信任根、主機名稱與有效期限驗證，不擴大 invalid-certificate 例外。
- 修正 Chrome 主文件導航與載入事件判斷，保留具體網路／憑證錯誤；國防院、故宮加入同一官方列表的正常 Chrome 備援。
- 修正 WDA 壓縮 RSS 串流未結束的逾時，仍優先 RSS，再以官方列表與分頁補足短 feed、合併去重。
- GitHub 日常 cloud 檢查 169 個來源，另 23 個有逐來源證據的環境限制明列須由 Mac 驗證。手動 full 與發布仍跑全部 192 個；最多 8 個且不超過 10%、重要來源、解析／存取／Chrome 及連續故障門檻保留。
- 增加清楚的雲端範圍摘要與 OS／Chrome／OpenSSL／curl 診斷，避免把 cloud 通過誤稱為全部來源或發布成功。

查核與既有實測見 [GitHub 來源檢查修正](GITHUB_SOURCE_SMOKE_REPAIR.md)。四部會新增／待確認／排除清單見 [四部會來源查核](four-ministry-source-audit.md)。

發布前檢查包含 PR／CI、發布時才啟動的 Mac 全量門檻、四平台建置與公開下載實測。門檻通過允許範圍內的網站暫時故障，不代表所有来源都成功；實際發布檢查結果將列於 GitHub Release。
