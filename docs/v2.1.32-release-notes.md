# 各機關新聞整理 v2.1.32

來源目錄由 88 個擴充為 192 個，新增文化部／陸委會 27 個、外交部 6 個、農業部 71 個。保留既有來源，外交部駐外館處本輪不展開。未取得有效發布入口的 52 個項目另列待確認，不加入預設收集；4 個排除項目記錄理由。逐機構關係、官方證據與固定樣本見[四部會來源查核](four-ministry-source-audit.md)。

- 72 個來源優先使用官方 RSS；短版、混合或不完整資料流用官方列表補足，保留 RSS 已取得內容後合併去重。
- RSS、HTML 與 JSON 在全文擷取前使用同一組收錄規則，保留展覽、活動、課程及藝術徵件，排除明確徵才與採購。HTML 與 RSS 都檢查全部分類。
- 發布日期優先於更新日期；Atom 優先文章連結，支援相對網址、英文日期與官方美式日期。缺失日期不猜測。
- 共用資料流依明確發布單位、官方分類或專屬路徑歸屬；作者及文章提及館舍不能作為發布機關證據。媒體法人只收機構自身消息及活動。
- 同型農業網站的 HTTP 暫時回傳 404 時，使用逐站核實的正常 Chrome 列表備援；不改寫 HTTP 失敗分類或放寬發布門檻。
- 分頁遇到故障、重複頁或頁數上限保留已取得新聞並如實記錄失敗；舊置頂公告不會提前終止補頁。
- 公路局加入官方 XML 全文備援，短版 XML／JSON 必須用正式列表補頁；補足失敗仍保留新聞並回報失敗。國土管理署新增正常 Chrome JSON 備援，使用原始 JSON，不把瀏覽器外框當資料。
- 正常跨路徑／跨頁重疊以精確文章鍵合併，保留全文及發布單位、分類、路徑、頁碼證據；同頁異常重複仍觸發原品質檢查。種苗場在來源 transport 設定啟用系統 Chrome 自身的版本與平台資訊，既有來源維持相容設定；瀏覽器先等待驗證頁結束，再執行新聞列表等待，並保留腳本例外原因。
- 跨機構去重需有母子關係及同一正式文章網址的轉載證據，兄弟機構同日同標題消息保留。
- GUI、CLI、日常檢查、發布及下載實測比對核准名冊的完整名稱集合與數量。失敗門檻仍為最多 8 個且不超過 10%，關鍵來源及解析／驗證頁門檻不變。

維持 JSON schema v4、Excel 17 欄、預設全文、相關性規則及國家標準時間功能。發布來源檢查沿用只接一個工作的本機 Mac 執行器，Rust 工具環境隔離在執行器暫存目錄；四平台建置及下載實測由 GitHub 執行。
