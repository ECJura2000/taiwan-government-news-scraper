## 搜尋及政策依據

既有標註集共 205 筆，80 筆標註為相關；新規則 TP=80、FP=0、FN=0，精確率及召回率均為 100%。既有規則另以保存的舊設定檢查分類相容性。這些數字限於該固定標註集，不代表所有未來新聞的表現。

新增 `TAICA`、`CryoCMOS` 政策案例由舊規則均未收錄，改善為兩筆均收錄；另驗證「量子技術與運算系統整合」可由核心片語拆詞召回為可能相關。同語意在標題命中的 BM25 分數高於僅在摘要命中，並檢查空集合、單篇及輸入順序改變的穩定性。

173 個加權詞中，135 個 PDF 原詞均核對其所列印刷頁碼，38 個補充詞另行標示。完整詞表及核對方法見 [政策詞來源核對紀錄](policy-keywords-audit.md)。

## 規則與匯出

已測試扣分與完全排除的差異、重複命中不重複扣分、多詞命中取最高扣分、甲排除而乙保留、停用規則及主題不生效、低於門檻仍保留規則分數，以及所有主題均無合格結果時的移除／保留區別。

匯入測試包括同名整筆取代、異名合併、清空後匯入、重複名稱、欄位及格式錯誤、共用設定差異、原子儲存失敗保留原設定及重新讀取。主題檔與 GUI 快照共用相同驗證及排序引擎。

實際國發會蒐集以 `--date 2026-09-09` 驗證：2 筆去重新聞，`status=success`，`failed_sources`、`anomalies`、`error_counts`、`quality.alert_reasons` 均為空；來源健康為 1 個正常、0 個失敗。CLI 檔案設定與 GUI 快照入口各執行一次，設定、品質摘要與 12 張新聞工作表 XML 完全一致。此項透過 GUI 所用 Rust 執行入口進行，並未另外全面蒐集其餘 71 個來源。

Excel 套件內容檢查確認所有新聞表僅「開啟原文」欄具有超連結，完全移除新聞不存在於共享字串或其他工作表。另檢查每主題獨立收錄、民國日期、工作表禁用字元、長度、重名及 Excel 保留名稱。

## 實際介面操作

使用獨立識別碼的桌面驗證版，完成兩主題範例匯入、合併／清空預覽、規則編輯、錯誤扣分值保留原設定、有效規則儲存、主題勾選、未選主題禁止執行、Escape 取消及焦點返回。關閉並重新開啟後，主題設定及深色偏好仍保留。

實際檢查淺色、深色、721 像素窄視窗及 200% 文字放大。文字大小提供 100%、125%、150%、200%，並記住選擇。按鈕及提示可閱讀，窄視窗改為單欄。

使用 Microsoft Excel 開啟獨立驗證活頁簿，確認來源欄可選取與複製、日期可選為 `115-08-31`，且「開啟原文」成功開啟國家發展委員會網站。操作前已等候使用者完成原活頁簿的儲存格編輯，未以測試檔覆寫原活頁簿。

本機畫面及測試紀錄保存在 `build/stage1-verification/`，依既有 Git 忽略規則不納入提交。範例檔透過 Tauri 資源設定納入安裝包，並另附於可攜式發布包；資源設定方式依 [Tauri 官方文件](https://v2.tauri.app/develop/resources/)。
