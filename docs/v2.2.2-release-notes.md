# v2.2.2

這次更新修正種苗場新聞入口與正文擷取，並統一跨平台規則指紋及改善瀏覽器 HTTP 失敗診斷。保留全部 192 個核准來源、JSON schema v4、Excel 17 欄與既有 TLS 政策。

- 種苗改良繁殖場改讀官方「農業新聞」入口 `sub_theme=news`，HTTP 列表與瀏覽器備援使用同一入口，保留官方分頁、發布日期與詳細頁連結。
- 新增種苗場正文區解析，排除頁面導覽、列印按鈕及附件區。歷史週實測成功收集 1 則新聞及約 896 字全文；2026-10-19 至 2026-10-25 的零則結果符合目前列表日期，不視為來源失敗。
- 政策指紋計算前將內建字典的 CRLF 換行統一為 LF，避免 Windows 與 Mac／Linux 對相同規則產生不同雜湊；原 Mac／Linux 指紋保持不變，政策及字典內容變更仍會反映在指紋中。
- Chrome 導覽明確失敗且取得目標文件 HTTP 狀態時，沿用 HTTP client 的既有分類，保留實際 403／404／503 等錯誤碼；正常驗證頁與其他請求不影響此診斷，沒有狀態證據時仍保留瀏覽器執行錯誤。

官網偶發連線失敗、驗證頁或 HTTP 404 仍會如實記錄。程式與套件測試通過不代表所有官網已恢復；本次完整來源與公開下載驗證結果會列於 GitHub Release。
