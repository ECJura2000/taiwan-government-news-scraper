## 制度關係查核

先由主管機關組織、所屬網站清單、捐助章程、預決算及持股清單建立機構母清冊，再查機構官網。每筆保留正式名稱、主管機關、直接上級、關係類別、證據網址、入口及啟用狀態。獲得補助、與政府合作或名稱與機關相近，不足以證明官方所屬或政府捐助關係。

| 關係 | 本次判定方式 |
|---|---|
| 官方所屬機關／機構 | 以組織法規及官方所屬清單確認；直接所屬與其下層分支分開記錄。 |
| 行政法人 | 保留行政法人身分；不將改制前的基金會或法人另外重複新增。 |
| 政府捐助法人 | 以官方捐助章程、捐助欄位及相關預決算證明，與只有主管關係的民間法人區別。 |
| 官方委託／特殊組織 | 依官方組織圖、章程或法規標明真實關係，不一律改稱政府捐助基金會。 |
| 政府持股／轉投資民營事業 | 以官方投資清單標明持股關係，不能一律稱國營事業。 |
| 館舍、工作站及管理處 | 記錄上級機構；是否有獨立新聞來源另行查核，不能用館名或網站數代替法定機關數。 |

農業部官方組織正文列 **15 個三級機關（構）、10 個直屬四級機構及 30 個下層機關（構）**，共 55 個；農田水利署 17 個管理處另為內部管理單位，不混入這 55 個機關數。其政府捐助章程頁列 24 家法人，年度預算頁所列筆數不等於完整捐助清單。

## 新聞入口與歸屬驗證

啟用來源須有實際官方 HTTP 回應或系統 Chrome 渲染結果，能對照發布日期、標題與正式文章連結，再以縮減的公共 HTML／XML 樣本通過 Rust `parse_route_records` 及 `filter.apply`。只有 RSS 圖示、可開啟的網站或機構介紹頁，不足以啟用。

RSS 優先採用經實測的 RSS／Atom，檢查實際 XML 根節點、日期及新聞類別。HTML 驗證頁、採購徵才流、新聞剪報、留言 feed 或不符機構新聞範圍的全站流不充作新聞 RSS。沒有合適 RSS 時，使用有證據的官方 HTML／JSON／Chrome 路徑；不能僅因沒有 RSS 就把來源視為不能收集。

共享網站與分支來源須由發布單位、官方分類或專屬路徑證明歸屬：

- 防檢分署採官方指向的 `/office/` 子站；農業試驗分所採分所專用 `Parser` 區段，不複製母機關全流。
- 農田水利管理處網站會混入母署新聞。只啟用已有自身日期消息、且分類實證符合「本處新訊」或其自有工作站／組別的管理處；精準 `include_categories` 排除母署新聞及協助宣導。沒有真實發稿單位時不補造 publisher。
- 真有發稿單位欄位的共享來源，使用明確 publisher 別名或帶單位邊界的機構前綴，避免文章僅提及某機關就被歸入該機關。
- 館舍沒有獨立日期新聞流時，保留關係與待確認原因，不以母機構全站新聞假稱館舍新聞。

水產試驗所實測發現「水產新聞提要」RSS屬剪報，因此改採[自身新聞稿 RSS](https://www.tfrin.gov.tw/wm_DATA.php?data=news_news)，並保留新聞列表備援。農業部花卉創新園區研究發展中心採[公開中心公告頁](https://www.fiic.gov.tw/announcements/messages)的 Chrome DOM；其官方程式公開查詢使用發布狀態，未把無狀態 API 中未公開項目或外部媒體 activity 轉載納入中心自身新聞。

媒體機構只收自身公告、新聞稿、節目及活動，不收每天採訪報導或轉載新聞網的全站日報。例如漁業廣播電臺採[電臺自身公告](https://www.frs.gov.tw/list.php?theme=announcement&subtheme=)，不採農漁業每日新聞及射擊日期排程。豐年社仍待確認自身消息入口，不以農傳媒全站新聞替代。

保留新聞、展覽、課程與公開活動；排除徵才、職缺甄選、採購、招標、決標等行政性訊息。不能把「公告」或「申請」等廣泛字詞全部當作非新聞，否則會誤刪政策、活動與業務消息。每次過濾保留原因及統計，既有來源仍保留；正常無新聞週、去重及非新聞過濾不等同來源失敗。

日期採官方發布日，保留原始日期與解析依據；不以活動舉辦日、頁尾更新日或推測值補發布日。固定樣本優先保留 2026-10-05 當週項目；無該週文章時保留真實近期項目，不改日期造樣本。

## 覆蓋範圍與尚存限制

RSS 篇數或日期範圍不足時補抓已驗證的官方列表，並合併去重；不能因 feed 可解析就宣稱指定期間完整。頁碼參數只在實際下一頁連結有證據時宣告，已宣告路徑的安全上限為 20 頁；到達上限仍未覆蓋指定期間時，應保留覆蓋不足證據。

[CAS 動態新聞頁](https://www.cas.org.tw/#/newslist)、花卉中心動態頁及[中央畜產會列表](https://www.naif.org.tw/allNews.aspx)的部分歷史分頁由前端按鈕或 ASP.NET 回傳處理，沒有任意虛構 `page` 參數。公開當頁已驗證，較早日期窗口仍須由正式收集診斷確認覆蓋，不能將當頁成功等同全部歷史期間成功。

待確認條目包括關係尚未證實、無獨立新聞歸屬、未取得可信日期／連結及暫時連線限制等不同情況，不能一律寫「沒有 RSS」或「機構不存在」。已驗證且啟用的來源發生暫時故障時保留來源與執行證據，不因單次故障從核准名冊刪除。
