# 各機關新聞整理 v2.1.31

本版包含 [v2.1.30 的 49 個官方 RSS 優先、88 來源查核及國家標準時間校正](v2.1.30-release-notes.md)，並修正發布實測發現的驗證頁處理。

- GitHub Linux／macOS 執行器讀取文化部 RSS 時，可能先收到 Cloudflare「Just a moment」頁面。原程式過早擷取內容，把驗證頁交給 RSS 解析器，誤報解析退化。
- 辨識有明確驗證頁標記的 Cloudflare 頁面，以及只有 Incapsula 載入程式的空白驗證頁；正常瀏覽器等待最長 30 秒，取得真正內容才解析。
- 等候後仍未完成驗證時，記錄 `access_blocked` 並保留失敗證據。RSS、新聞全文與日常／發布品質檢查都不會將驗證頁當成有效新聞。
- 正常新聞頁即使載入相關服務的程式，也不因資源網址而被誤判；RSS 內介紹驗證頁的新聞亦不會被誤判。

保持 88 個來源、49 個 RSS 優先來源、CLI、JSON schema v4、Excel 17 欄、預設完整處理及原本發布門檻。既有簽署標籤維持不變；不加入 TLS 例外或自動 CAPTCHA 解題。
