# 各機關新聞整理 v2.1.25

修正 Excel「所屬單位」欄混入網站版權聲明、新聞類別與重複機關名稱的問題。

- 高速公路局：忽略 RSS 網站版權聲明，保留真正的發布單位；仍支援經濟部「版權來自」的單位資料。
- 文策院、國防部與國家文化藝術基金會：新聞、新聞稿、新聞澄清及一般公告只保留在分類欄，不再當成所屬單位。
- 偵防分署與艦隊分署：匯出時合併海巡署全名與簡稱，避免重複的上級機關路徑。

維持 88 個來源、17 欄 Excel、JSON schema v4 與 CLI／Tauri 共用服務。已有的本機週報已精準修正；本次發布不包含週報、執行紀錄或任何本機資料。

新增回歸檢查並通過 Rust 測試、Clippy、前端檢查與建置。下載後請以本版 SHA256SUMS 與 SIZE-MANIFEST 驗證。動態來源需要系統 Chrome／Chromium。
