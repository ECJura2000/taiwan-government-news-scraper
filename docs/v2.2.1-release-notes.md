# v2.2.1

這次更新修正新聞漏收與正文缺漏，保留全部 192 個核准來源、預設全文收集、JSON schema v4 與 Excel 17 欄格式。

- 最高檢察署改讀正式新聞列表，辨識標題中的民國發布日期，避免新聞因缺少日期而被週篩選略過；保留官方分頁與 PDF 原文連結。
- 新增直接連結 PDF 的中文正文擷取。解析在獨立程序執行，限制檔案大小、頁數、文字量與執行時間；損壞、超限、加密或沒有可擷取文字的附件會保留連結與失敗原因，不中斷整批收集。不提供掃描式 PDF 的 OCR，也不自動下載 HTML 新聞的全部附件。
- 修正漁業署正文區解析，排除日期、點閱率與頁面導覽。
- 瀏覽器新聞列表與分頁遵守來源明確宣告的處理期限；未宣告的來源維持原行為。
- 修正未完成 HTTP 轉址被誤判為內容解析錯誤的情況，沿用既有重試政策。
- 修復相依套件、編譯與前端測試相容性，並改善環境部官方開放資料備援及嘉南管理處來源恢復。環境部開放資料備援仍標示覆蓋受限。

收錄範圍涵蓋中央部會、所屬機關、館舍、政府捐助法人及政府投資事業的官方發布入口。完整來源以 [核准目錄](../src-tauri/resources/approved_sources.json) 為準；四部會來源的依據與待確認項目見 [來源查核](four-ministry-source-audit.md)。

官網連線、驗證頁與暫時性 404 仍可能造成個別來源失敗，請查看當次 JSON 的失敗來源與品質警示。發布前會重新執行 Mac 的完整來源閘門及四平台建置；實際發布驗證結果另附於 GitHub Release，不能以程式測試通過代表所有官網已恢復。
