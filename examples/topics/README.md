# 搜尋主題 JSON 範例

- `ai-ten-topics.json`：可直接匯入的完整十大主題，與程式內建設定相同。184 個加權詞包含民國 115 年 1 月核定本原詞及另附官網依據的新聞用語。
- `two-topics.json`：兩主題最小範例，示範「研討會」扣 20 分、「徵才」完全排除；量子科技主題獨立適用。

在程式「搜尋主題」選擇「匯入 JSON」，檢視新增、取代及刪除清單後確認套用。合併保留不同名主題，同名主題整筆取代（包含原扣分及完全排除規則）；清空後匯入則使用新清單。匯入設定與勾選狀態會儲存於使用者的應用程式設定目錄。

每份檔案可含一個或多個 `initiatives`。可自行新增、刪除主題；`enabled: false` 表示暫停適用。主題名稱比對統一全半形、英文大小寫及空白。同一檔案內不得重名。

## 關鍵詞及權重

`weighted_keywords` 每項包含 `text`、`weight`、`enabled`、`origin`、`references`。權重須大於 0 且不超過 100；核心詞預設 3，脈絡詞預設 1。權重至少 3 的詞亦作為核心片語判讀，低於 3 為輔助脈絡。舊有 `strong_keywords`、`context_keywords` 與 `exact_phrases` 字串陣列仍可使用。

PDF 原詞以 `origin: "pdf"` 標示，`references` 記錄網址、版本、章節及印刷頁碼；PDF 檢視器頁碼為印刷頁碼加 2。`synonym` 表示人工補充之同義詞或既有範本詞，並非 PDF 原文。自行新增用 `origin: "custom"` 及空的 `references`。數值為本程式搜尋參數，不表示政府公布的政策優先順序。

共用 `scoring` 預設為 `k1=1.2`、`b=0.75`、`title_weight=3`、`summary_weight=1`、`general_weight=0.5`。同一查詢詞取最高權重；標題及摘要分別計算 BM25 後加權。相關性類別依規則分數判定，同級再依 BM25 排序。共用設定未提供時，合併保留既有值；若提供 `scoring` 或 `thresholds`，即取代該整段設定，省略的子欄位補預設值，預覽會顯示實際變更。

## 扣分詞與完全排除詞

兩類規則均放在所屬主題內，可自行增刪與啟停。

- `penalty_keywords`：`text` 為詞句、`penalty` 為 0–100 的扣分值、`enabled` 控制適用、`match_fields` 可為 `["title"]`、`["summary"]` 或兩者。新增規則省略扣分時為 50，省略比對欄位時為兩者。重複出現不重複扣分，多詞命中取最高扣分值。
- `exclude_keywords`：同樣指定詞句、適用狀態與比對欄位；命中正向符合該主題的新聞後，該主題直接排除，高分不抵銷。

甲主題排除、乙主題仍符合納入門檻時，乙與總表保留；沒有其他合格主題收錄時，才從全部新聞、初篩及機關工作表移除。未觸發完全排除、僅未符合主題的新聞仍留於總表。禁用詞採詞句比對，不作模糊斷詞擴張。

舊版頂層 `negative_keywords` 自動轉成每個匯入主題的扣分規則，保留原本標題扣分行為，不轉為完全排除。

## 命令列

```sh
cargo run --release --bin news-scraper -- collect --topics-json examples/topics/ai-ten-topics.json --date 2026-08-31
```

未指定 `--topics-json` 時使用內建設定，不讀取桌面介面的個人設定。檔案須為 UTF-8（可含 BOM）、不超過 2 MiB，最多 100 個主題。錯誤設定於開始蒐集前即拒絕執行。空清單可儲存，但須至少啟用一個主題才能執行。
